# Política de Privacidade — Gov.ao Ficheiros

*Última atualização: 08 de setembro de 2026*

O Gov.ao Ficheiros é a aplicação oficial de armazenamento e partilha de
ficheiros para as equipas do Governo de Angola, disponibilizada e operada
pelo **Instituto de Modernização Administrativa (IMA)**. Esta política
descreve que dados são recolhidos quando utiliza a aplicação, para que
servem, onde ficam guardados e quais são os seus direitos.

## 1. Quem é responsável pelos seus dados

O IMA é o responsável pelo tratamento dos dados pessoais recolhidos através
do Gov.ao Ficheiros, nos termos da Lei n.º 22/11 (Lei de Proteção de Dados
Pessoais de Angola).

## 2. Dados que recolhemos

Ao utilizar o Gov.ao Ficheiros, podemos recolher e tratar os seguintes
dados:

- **Dados de conta** — as suas credenciais de acesso são introduzidas
  diretamente no ecrã de autenticação do servidor `gov.ao` (não no ecrã da
  aplicação); a aplicação guarda apenas a sessão resultante, necessária
  para se manter ligado.
- **Ficheiros e pastas** — o conteúdo que envia, sincroniza ou consulta
  através da aplicação. Estes ficheiros ficam armazenados no servidor
  `gov.ao`, operado pelo IMA — a aplicação é apenas o cliente que os
  apresenta e sincroniza.
- **Câmara** — usada quando escolhe digitalizar um documento ou tirar uma
  fotografia dentro da aplicação, para depois carregar esse conteúdo.
- **Microfone** — usado apenas quando decide gravar uma nota de voz para a
  carregar como ficheiro.
- **Fotos** — acesso à sua biblioteca de fotos apenas quando escolhe
  carregar uma foto existente ou guardar uma recebida através da
  aplicação.
- **Localização** — apenas se ativar, nas Definições, o carregamento
  automático em segundo plano; nesse caso a aplicação usa a sua
  localização só para detetar que se moveu e assim decidir quando
  verificar se há ficheiros novos para carregar. **Não usamos GPS e não
  guardamos o seu histórico de localização** — a localização não é
  enviada para o servidor nem para nenhum serviço de terceiros.
- **Reconhecimento facial (Face ID)** — usado apenas para desbloquear a
  aplicação no seu próprio dispositivo. Os dados biométricos são geridos
  inteiramente pelo iOS e nunca chegam a esta aplicação nem aos nossos
  servidores.
- **Contacto selecionado ao partilhar um ficheiro** — se escolher
  partilhar um ficheiro por email através da aplicação, esta abre o
  seletor de contactos do próprio iOS; só o endereço de email que
  selecionar nesse momento é usado, para preencher o convite de
  partilha. A aplicação não acede à sua lista de contactos fora deste
  momento, nem a sincroniza ou armazena.
- **Token de dispositivo (push)** — um identificador técnico do seu
  dispositivo, usado exclusivamente para lhe entregar notificações sobre
  ficheiros partilhados consigo.
- **Dados de diagnóstico (relatórios de falha)** — se a aplicação
  encontrar um erro grave, são recolhidos automaticamente dados técnicos
  sobre esse momento (modelo do dispositivo, versão do sistema, e o ponto
  do código onde ocorreu o erro), para nos ajudar a corrigi-lo. Estes
  relatórios não incluem o conteúdo dos seus ficheiros.

Não usamos a aplicação para lhe mostrar publicidade, não vendemos os seus
dados, e não os usamos para o seguir entre aplicações ou sítios de
terceiros («tracking»).

## 3. Onde os dados são guardados

Os seus ficheiros e dados de conta são armazenados e processados em
infraestrutura do Governo de Angola, operada pelo IMA. Não partilhamos
estes dados com o fabricante original do software em que esta aplicação se
baseia (Nextcloud GmbH), nem com qualquer serviço de nuvem de terceiros
para fins alheios ao funcionamento da aplicação.

## 4. Serviços de terceiros envolvidos

Para lhe entregar notificações, o token do seu dispositivo é encaminhado à
Apple (Apple Push Notification service) através de um servidor de push
próprio operado pelo IMA — o mesmo mecanismo padrão usado por praticamente
todas as aplicações iOS. Nenhum conteúdo dos seus ficheiros é partilhado
com a Apple para este fim.

Usamos o **Firebase** (Google), num projeto próprio e dedicado a esta
aplicação, para dois fins limitados:

- encaminhar o token de notificações push (ver acima);
- recolher os relatórios de falha automáticos descritos na secção 2.

Nenhum destes serviços é usado para publicidade, análise de comportamento
ou seguimento entre aplicações.

## 5. Os seus direitos

Nos termos da Lei n.º 22/11, tem o direito de:

- Aceder aos seus dados pessoais;
- Solicitar a correção de dados incorretos ou incompletos;
- Solicitar a eliminação dos seus dados, nos casos previstos na lei;
- Opor-se a determinados tratamentos de dados.

Para exercer qualquer um destes direitos, contacte-nos através de:
**mario.domingos@ima.gov.ao**

## 6. Base legal do tratamento

O tratamento destes dados é necessário para prestar o serviço de
armazenamento e partilha de ficheiros aos funcionários e colaboradores do
Governo de Angola, no âmbito das suas funções.

## 7. Alterações a esta política

Esta política pode ser atualizada periodicamente. A data da última
atualização é sempre indicada no topo deste documento.
